# Барановичи ближе

Онлайн-версия: https://tsururik.github.io/baranovichi-blizhe/ (публикуется автоматически из ветки `main` через GitHub Actions).

Интерфейс сайта полностью на английском языке. Тексты лежат в `src/App.tsx`, `src/components/`, `src/data/` и `src/config/`.

Оформление: шрифт Schibsted Grotesk (Google Fonts, подключён в `index.html`), цвета — переменные в начале `src/styles.css`. Все значки — SVG из набора Lucide с одинаковой толщиной линии; маркеры карты рисуются в `src/components/map/TravelMap.tsx`. Текстовые стрелки и символы (↗ → ◷) в интерфейсе не используются.

Готовый локальный демонстрационный сайт на React + TypeScript + Vite + Tailwind CSS + React Leaflet + Lucide React.

## Запуск

Нужен Node.js 22.12+ (или 24 LTS) с npm.

```sh
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно http://127.0.0.1:5173). Сервер работает, пока открыт процесс. Остановка: Ctrl+C. Файлы dist нельзя открывать двойным щелчком: используйте HTTP-сервер.

```sh
npm run build
npm run preview
npm test
```

Браузерный сценарий: запустить dev-сервер на 5173, затем `npx playwright install chromium` и `npm run test:browser`. Контрольные снимки сохраняются в `../../work/qa` относительно проекта.

## Как редактировать

### Название и логотип

В `src/config/site.ts` измените `name`, `tagline`, `contact`. Знак логотипа (линия маршрута от города к Барановичам) — SVG в `src/components/Logo.tsx`. Для собственного логотипа положите файл в `public/images` и задайте `logo: 'images/logo.svg'` (путь без ведущего `/`, иначе на GitHub Pages файл не найдётся). Главный заголовок первого экрана находится в `src/App.tsx`; метаданные вкладки — в `index.html`; маленькая иконка — `public/favicon.svg`. Не добавляйте несуществующие контакты и реквизиты.

### Маршруты и описания

В `src/data/routes.ts` — названия, города, рекомендуемая продолжительность, остановки и рекомендации по питанию. `stops` хранит ссылки на `attractionId` и порядок `order`. В `src/data/attractions.ts` — единственная запись для каждого места: название, описание, координаты, длительность визита, категория, фотография и источник координат. Мир и Несвиж не дублируются между маршрутами.

Ссылки на маршруты: `/?route=minsk#map`, `grodno`, `brest`, `mogilev`, `gomel`, `vitebsk`. Кнопка «Share this route» копирует текущую ссылку. Онлайн-ссылки вида https://tsururik.github.io/baranovichi-blizhe/?route=gomel#map можно отправлять другим людям.

### Цены и скидка

Единственное место настройки — `src/config/pricing.ts`:

- `prices` — стартовая цена за человека в BYN для каждого города отправления;
- `studentDiscountPercent` — скидка для студентов в целых процентах (сейчас 20);
- `label` — подпись «Starting price», `note` — примечание под ценами (группы от 35 человек);
- `maxTravelers` — максимум участников в калькуляторе.

Студенческая цена нигде не хранится отдельно: она вычисляется из стартовой цены и скидки в `src/lib/pricing.ts`. Поэтому предложение на первом экране («from 87.20 BYN»), карточки маршрутов, панель у карты, программа маршрута и калькулятор всегда показывают одни и те же суммы. Расчёт ведётся в целых копейках, без ошибок округления.

| Город | Стартовая цена | Для студентов (−20%) |
|---|---:|---:|
| Минск | 125 BYN | 100 BYN |
| Гродно | 109 BYN | 87,20 BYN |
| Брест | 119 BYN | 95,20 BYN |
| Могилёв | 155 BYN | 124 BYN |
| Гомель | 279 BYN | 223,20 BYN |
| Витебск | 249 BYN | 199,20 BYN |

Калькулятор: обычные участники × стартовая цена + студенты × стартовая цена × 0,8. Пример: Минск, 5 участников, из них 3 студента — 2 × 125 + 3 × 100 = 550 BYN, экономия группы 75 BYN. Студентов не может быть больше, чем участников: калькулятор сам уменьшает число и показывает подсказку.

Все цены предварительные, рассчитаны для демонстрации и для организованных групп от 35 человек. Сайт не утверждает, что питание, проживание, музейные билеты или обратная дорога входят в стоимость. Чтобы убрать все суммы с сайта, установите `enabled: false`.

### Фотографии и лицензии

Заменяйте файлы в `public/images`, сохраняя имена, либо меняйте `image` в справочнике. Галерея Мира и Несвижа настроена в `RouteDetails.tsx`. Для любой новой фотографии добавьте автора, страницу источника, лицензию и ссылку на её текст в `src/data/photoCredits.json` и `public/images/credits.json`. Подвал и галерея показывают атрибуцию. Текущие фотографии — Wikimedia Commons, CC BY/CC BY-SA. Масштабирование и кадрирование отмечены; условия лицензий исходных фотографий сохраняются. Заглушка не маскируется под подлинный снимок.

### Карта и дороги

Подложка — Esri World Street Map (подписи городов на английском), она требует интернета. Фотографии, тексты и GeoJSON локальны. Это не полностью офлайн-карта: перед лекцией откройте страницу с доступом в интернет. Массовая загрузка тайлов не выполняется. Для коммерческой нагрузки нужен подходящий договор с поставщиком карт или собственные тайлы; адрес меняется в `src/config/site.ts`.

Все шесть дорожных геометрий получены однократно 8 октября 2026 года через OSRM-совместимый демонстрационный сервис routing.openstreetmap.de и сохранены в `public/routes`. Страница никогда не обращается к этому маршрутизатору. Источник, время получения и флаг `demoOnly` записаны в каждом GeoJSON. Метрики — расчёт для поездки от города отправления до Барановичей через остановки, без обратной дороги, экскурсионных пауз, парковки, пробок и ночлега. Это оценка сервиса, не гарантия длительности. Точки городов и объектов не являются подтверждёнными местами посадки или парковки. Геометрия не должна использоваться для навигации водителя без проверки.

Для обновления подключите свой или согласованный OSRM-совместимый сервис:

```sh
ROUTING_BASE_URL=https://your-routing.example npm run routes:fetch
```

Не используйте публичный демонстрационный сервер как основу коммерческого продукта. Адаптер находится в `src/lib/routing.ts`. При отсутствии или невалидности локального GeoJSON включается честно подписанная пунктирная «Route outline», без выдуманных километров. После изменения остановок перегенерируйте соответствующий GeoJSON или удалите устаревший файл, чтобы включить схему.

### Заявки

Работает проверка имени, контакта, даты, количества участников и студентов. После подтверждения формы появляется предпросмотр с кнопкой копирования. Заявка никуда не отправляется и не сохраняется на сервере. Никаких платежей и подтверждений бронирования нет.

Для реального запуска замените адаптер `src/lib/application.ts`, добавьте серверную валидацию, обработку ошибок, согласованные правила работы с контактными данными и интеграцию CRM/email. Секреты CRM нельзя помещать в клиентский код. После подключения сервера потребуется отдельная проверка фактической отправки и сообщения о её результате.

## Лекция

1. Откройте сайт; оптимальная проверенная область экрана — 1920×1080.
2. Нажмите «Explore the map», затем «Presentation mode».
3. Выбирайте города кнопками или стрелками ← →. В полях ввода и на самой карте стрелки сохраняют своё обычное назначение. Esc выходит из презентации.
4. Выберите остановку в правом списке или на карте: появятся фотография и описание.
5. В панели у карты нажмите «Calculate the trip»: калькулятор получит выбранный маршрут. Задайте число участников и студентов.
6. Сформируйте и скопируйте пример заявки. Это не отправка оператору.

## Что готово и что требует интеграции

Работают: шесть маршрутов, дорожные линии, карта с мышью/касанием/клавиатурой, маркеры, список остановок, фотографии и галереи, программа, дополнительный железнодорожный музей, калькулятор, валидация заявки, копирование, URL маршрутов, адаптивность, reduced-motion, режим презентации и FAQ.

До коммерческого запуска нужны: утверждение цен/условий/состава услуг, подтверждение дат и мест отправления, договорённости с транспортом и музеями, реальные контакты, backend/CRM/email, подходящий картографический и routing-сервис, развёртывание на выбранном хостинге. Платежи не реализованы и не имитируются.

Браузерный WebMCP `select_travel_route` дополнительно доступен в поддерживающих его браузерах. В обычном браузере сайт работает без него.
